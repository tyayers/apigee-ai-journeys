Welcome to the Apigee AI Gateway Tester

Apigee X on GCP, can be duplicated with Apigee hybrid to AWS, Azure or K8s on-premise

You can try out the Antigravity and Claude desktop apps and CLIs (agy, claude) directly in this VM using the Apigee AI Gateway, and use this tester app to explore and test these use-cases:

  • OAuth 2.1 Scoped Tokens — Mint short-lived RS256 JWTs with fine-grained scopes (starter-models, advanced-models, customer-viewer, customer-admin).
  • Health-Aware AI Router & KVM Controls — Test multi-region failover, x-data-classification EU residency enforcement, Model Armor prompt screening, DLP PII masking, smart model routing, and live AI-Demo KVM configuration.
  • Antigravity & Claude Gateways — Test the /antigravity and /claude proxies with GoogleAccessToken target auth, LLMTokenQuota enforcement, and cached token cost analytics.
  • A2A & MCP Governance — Invoke scoped Agent-to-Agent (A2A) skills, MCP tools, and an interactive Customer Agent backed by the AI Router.

Visit the Apigee AI Portal (opens in a new tab) to view your subscriptions and analytics usage, or open the Apigee Proxies link in the parent app Links dialog and filter by ai-platform to inspect the proxies used.

Test AI Router

        

          Apigee X on GCP, can be duplicated with Apigee hybrid to AWS, Azure or K8s on-premise
          
        

        
Get an access token on the Token & Config tab first.

        

          Calls ai-platform-router with your token & prompt configuration.
        

        

          Suggested Use Cases to Test:
          
    
            
  • Regional Routing: Try a basic eu, us, or global endpoint request.
    • 
            
  • Health-Aware Failover: Throttle or stop a region in Token & Config → AI-Demo KVM Properties and watch traffic load-balance to healthy regions via 307 redirects.
    • 
            
  • Data Residency: Check x-data-classification: true and target us / us-east1 (blocked with 503) vs. eu / europe-west3 / europe-west10 (allowed).
    • 
            
  • Prompt Security: Toggle x-screen-prompt: true (Model Armor) or x-mask-prompt: true (DLP PII masking).
    • 
            
  • Smart Router & Proportions: Select smart as the model to route prompts by complexity, and adjust lite-model-percent / medium-model-percent / thinking-model-percent in Token & Config → AI-Demo KVM Properties.

Terminal (agy)

            
Open a terminal in your workspace and start an interactive session or one-shot prompt:

            
agy
